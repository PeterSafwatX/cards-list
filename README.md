# cards-list

An open gallery of personal cards. Every contributor adds one self-contained HTML page: a
card showing their own details, and a button that switches the page between light and dark.

Vanilla HTML, CSS, and JavaScript only. No frameworks, no libraries, no build step — you
open an `.html` file in a browser and it works.

If you have never opened a pull request before, this is a good one to start with. Adding
your card is a real contribution to a real repository, small enough to finish in an
evening.

---

## What you build

A single page containing:

1. **A card** showing your personal information — profile photo, name, job title, company.
2. **A dark mode button** that switches the colors of the whole page *and* the card.
3. **Dynamic information** — your details live in a JavaScript object and get written into
   the card by JavaScript. Nothing personal is typed between the HTML tags.

How it looks is entirely up to you. Same four pieces of information, as many different
cards as there are people.

## Contributing

Fork the repo, add `<your-github-username>.html` to the root, open a pull request.

[**CONTRIBUTING.md**](CONTRIBUTING.md) has the full walkthrough — the fork-and-branch
steps, what belongs in the file, and what reviewers check before merging.

## Ground rules

- **One file.** Markup, styles, and script all live in your single `.html` file.
- **One card per person.** Already have one? Edit it rather than adding a second.
- **Vanilla only.** No frameworks, no libraries, no build tooling, no npm.
- **Your own information.** Don't add a card for someone else.

## Examples

Every `.html` file in the root of this repo is a finished card. Open a few in your browser
and read the source — that's the fastest way to see what a finished submission looks like.
